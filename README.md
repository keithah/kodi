# Keithah Kodi Add-ons

This repository is a Kodi add-on repository. Install the repository zip, then use Kodi's add-on browser to install or update Chorus 3.

## Install

1. Download the repository add-on zip:
   https://raw.githubusercontent.com/keithah/kodi/main/repository.keithah.kodi/repository.keithah.kodi-0.1.0.zip
2. In Kodi, use Add-ons > Install from zip file.
3. Then use Install from repository > Keithah Kodi Add-ons > Web interfaces > Chorus 3.

Kodi repository metadata is served from:

- https://raw.githubusercontent.com/keithah/kodi/main/addons.xml
- https://raw.githubusercontent.com/keithah/kodi/main/addons.xml.md5
